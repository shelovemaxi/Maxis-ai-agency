Transparent methodology

Signals are collected by a scheduled GitHub Action from free public RSS/Atom feeds, GDELT, and USGS. Rule-based phrase weights identify potential market relevance; percentage moves add a capped boost. Duplicate titles are collapsed and distinct-source corroboration adds points. High is 60+, Medium is 30–59, and Low is below 30.

No account, API key, X/Twitter scrape, or paid World Monitor API is used. Open the original sources before acting. This is research, not financial advice.
